# Animación: cardinalidades, esquema estrella y galaxia

Video hecho con [Remotion](https://www.remotion.dev/) (React + SVG).

- `npm install`
- `npm run studio` → vista previa interactiva
- `npm run render` → genera `out/db-modeling.mp4` (1080p, 30 fps, ~57 s)

El video ya renderizado está en `video/db-modeling.mp4`.
